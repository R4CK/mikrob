# Magyar AI-ujjlenyomatok -- szólista és példák

## Feltöltőszavak (töltőszó, filler)

Töröld vagy cseréld konkrét tartalomra:

```
kétségtelenül, kétség nélkül, vitathatatlanul
fontos megjegyezni, fontos kiemelni, megjegyzendő
ne feledjük, érdemes megjegyezni
különböző (ha nem sorolja fel)
jelentős, lényeges, számottevő (szám nélkül)
nagymértékben, jelentősen, erőteljesen
optimális, ideális (ha nincs mérőszám)
holisztikus, szinergikus, paradigma
```

## Chatbot-klisé (töröld)

```
Természetesen!
Szívesen segítek!
Remek kérdés!
Remélem, segített!
Ha bármiben segíthetek, szólj!
Összefoglalva tehát...
Ezekből látható, hogy...
Mint mesterséges intelligencia, ...
```

## Halmozott óvatoskodás

Ezeket le kell egyszerűsíteni -- egy bizonytalansági marker elég:

```
talán esetleg érdemes lehet fontolóra venni
potenciálisan lehetséges, hogy bizonyos esetekben
ez esetlegesen előfordulhat néhány helyzetben
```

## Névtelen tekintély

Nevesítsd vagy töröld:
```
A kutatások szerint...
A szakértők szerint...
Tanulmányok azt mutatják...
Statisztikák szerint...
```

## Szenvedő szerkezet / alanyhiány (magyarosítás)

| Szenvedő | Aktív |
|---|---|
| Figyelembe véve ezt, az eredmény... | Ha ezt figyelembe vesszük, ... |
| Elvégezve a lépéseket, a rendszer... | Ha elvéged a lépéseket, a rendszer... |
| Megvizsgálva az adatokat, látható... | Az adatokat megvizsgálva látjuk, hogy... |
| Ez szükségesnek tekinthető. | Erre szükség van. / Ezt ajánljuk. |
| Az ajánlott megközelítés... | Javasolt megközelítés: ... |

## -va/-ve lógó mellékmondat

A mellékmondat alanya legyen azonos a főmondat alanyával, vagy tedd ki explicit.

| Lógó | Javított |
|---|---|
| Figyelembe véve a kockázatokat, a döntés helyes. | Ha figyelembe vesszük a kockázatokat, a döntés helyes. |
| Átnézve a dokumentumot, hibák találhatók. | Az dokumentumot átnézve hibákat találunk. |

## not-X-but-Y sablon (eltávolítás)

Ezek az alakzatok üresek, ha nincs mögöttük tényleges különbség:

```
Nem csak egy eszköz, hanem egy partner.
Nem egy szoftver, hanem egy megoldás.
Nem a technológia, hanem az ember a lényeg.
```

Csere: mond el konkrétan, mit csinál, amit mások nem.

## Mély mondások (töröld vagy konkretizálj)

```
A nap végén minden az emberekről szól.
A siker útja az apró lépésekben rejlik.
Az igazi változás belülről fakad.
Ez több mint technológia -- ez egy közösség.
```

## Fejléc-ismétlés

| Fejléc | Ismétlő első mondat (töröld) |
|---|---|
| Hogyan kezdj el? | Az elkezdés egyszerű. |
| Miért válasszon minket? | Sok okból érdemes minket választani. |
| Eredmények | Az alábbiakban az eredmények láthatók. |

## Hosszú felvezetés (vágj)

Ha az első 2-3 mondat nem visz közelebb a lényeghez, töröld. Teszt: "Mit tenne az olvasó, ha kihagynám ezt a bekezdést?" -- ha semmit, ki is hagyhatod.

## Szalmabáb-vita

Csak akkor hozd fel az ellenvetést, ha valóban foglalkozol vele részletesen. Ha csak látszólag kérdőjelezel meg valamit és utána elhullajtod, töröld az egész felütést.
