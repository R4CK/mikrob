# Webinar Marketing

## Mikor használd
Webinar-stratégia tervezésekor, promóciós kampány írásakor, tartalom-struktúra kialakításakor, vagy post-webinar follow-up sorozat összerakásakor.

## Eljárás

### 1. Téma és pozicionálás
**Jó webinar téma = sürgős probléma + specifikus közönség + mérhető kimenet**

Formula: "Hogyan [konkrét eredmény] [közönség] számára [időkeret alatt / feltétel]"
- "Hogyan csökkentsd 40%-kal az inspekciós dokumentáció idejét facility managereknek 90 nap alatt"
- "Hogyan nyerj visszatérő szerződést takarítócégként -- az első ajánlattól a megkötésig"

Kerülendő: "X bemutatása", "Trendek 2026-ban" (generikus, nincs ígéret).

### 2. Promóció ütemterv (4 héttel előre)
```
T-28 nap: Regisztrációs oldal él, első email blast (saját lista)
T-21 nap: Social posts (LinkedIn + Twitter, 3-4 poszt)
T-14 nap: 2. email (testimonial / speaker hitelességgel)
T-7 nap:  Partner promóció / co-host announcement
T-3 nap:  "Csak X helyek maradt" reminder
T-1 nap:  Napelőtti emlékeztető
T-0 hónap: 1 órával start előtt: link küldés
```

### 3. Regisztrációs oldal elemek
- **Headline:** A téma + a konkrét ígéret
- **Ki fog részt venni (speaker bio):** Hitelességre fókuszálva (nem CV, hanem tapasztalat)
- **Mit viszel haza:** 3-4 konkrét takeaway (bullet)
- **Kinek szól:** Explicit közönség-szűrő ("ha X vagy, ez neked szól")
- **Logisztika:** Dátum, időtartam (max 45-60 perc), platform
- **CTA:** "Foglald le a helyed" nem "Regisztrálj"

### 4. Webinar tartalom struktúra (45 perc)
```
0-5 perc:    Hook -- a probléma, amit megoldasz (nem bemutatkozás)
5-10 perc:   Bemutatkozás -- rövid, releváns (miért hallgass rám?)
10-35 perc:  Tartalom -- 3 fő pont, konkrét példákkal
35-40 perc:  Demo / live példa (ha releváns)
40-45 perc:  Q&A + CTA (egy ajánlat: trial, discovery call, resource)
```

### 5. Follow-up sorozat (3 email, 7 napon belül)
- **D+0 (aznap):** Köszönő + felvétel link + beígért resource
- **D+2:** A legfontosabb takeaway összefoglalva + egyedi CTA
- **D+5:** "Miben segíthetek tovább?" -- discovery call / demo ajánlat

### 6. Konverzió optimalizálás
- Live poll-ok az engagement fenntartásához
- Chatbox aktív moderálása -- Q&A-t ne hagyd silóba süllyedni
- "Exkluzív webinar-ajánlat" az utolsó 5 percben -- live kedvezmény/bónusz
- Felvétel: de-gate-eld (ingyenes hozzáférés = több share), vagy gate + email capture

## Kimenet
1. Téma + headline javaslat(ok).
2. Promóciós ütemterv emailekre és social posztokra.
3. Regisztrációs oldal szöveg.
4. Webinar tartalom-vázlat.
5. Follow-up email sorozat (3 email).

## Buktatók
- Túl hosszú: 60+ perc = drop-off. 45 perc az optimum.
- Demo-heavy nyitás: az emberek a problémájukra kíváncsiak, nem a termékre.
- Egy CTA-nál több a webinar végén: "vagy trial, vagy call, vagy ebook" = senki nem csinál semmit.
- Follow-up késlekedés: ha D+3 után küldöd az első emailt, elveszted a momentumot.

## Ellenőrzés
- A webinar cím tartalmaz konkrét ígéretet?
- A follow-up sorozat 24 órán belül indul?
- Van egyetlen, egyértelmű CTA a webinar végén?
- A tartalom 80% value, 20% pitch?
